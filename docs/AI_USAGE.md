# AI usage

Per ETHGlobal rules, this documents where AI tools were used.

- **Claude Code** was used for research (bounty docs, API shapes), writing the spec in
  `docs/spec.md`, and generating code across `connector/`, `web/` and `contracts/` under
  the team's direction. That includes the web app's redesign (dark theme, landing, the
  agent pages, dialogs and dashboards), iterated screen by screen from the team's
  feedback. The team chose the product and the design direction, reviewed every change
  and tested it.
- **Codex** may be used for the testing pass; its prompt is kept in `docs/prompts/`.

All planning artifacts used to build this are in `docs/`.
